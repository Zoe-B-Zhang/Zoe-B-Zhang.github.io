This project is a submission for the [Google DeepMind - Vibe Code with Gemini 3 Pro in AI Studio](https://www.kaggle.com/competitions/gemini-3/writeups) hackathon on Kaggle. Travel Route Recorder is an interactive web application that transforms simple text itineraries into beautiful, visual travel memories.

## Project Overview

Travel Route Recorder uses AI to geocode travel stops from loose text (e.g., "London, Paris, Rome"), plots them on an interactive map, and generates unique passport-style stamps for each location. It is built with Angular, Leaflet.js for maps, and Google's generative AI APIs.

## Technology Stack

- **Framework:** Angular (v21+)
- **Styling:** Tailwind CSS
- **Maps:** Leaflet.js
- **AI:** Google GenAI SDK (Gemini & Imagen)
